# Page grammar, Visual Story and scroll score

**Status:** active design plan / D-060  
**Candidate family:** Pattern Assembly

## New page grammar — Pattern Assembly

Scrollcraft permits a new grammar when its navigation, sequence, ending and bans define a genuinely different structure. Pattern Assembly is specific to a uniform-program business.

### Structural idea

The visitor alternates between **worn context** and **made object** while a persistent pattern/stitch trace proves they belong to the same system.

The page is not a sequence of cards. It behaves like a garment/program being assembled.

### Navigation

- restrained Fares wordmark and primary action;
- a thin stitch/progress trace doubles as scene orientation on large screens;
- mobile uses a persistent compact bar plus direct route menu;
- project skin never recolours the permanent Fares wordmark/chrome.

### Opening

A dimensional real-media composition:
- campus/context plane;
- typography plane;
- worn-person plane;
- garment/material plane;
- foreground stitch/pattern plane.

No fake generated scene and no flat “big image + heading” hero.

### Sequence

1. context;
2. people/program;
3. selection/range;
4. worn-to-garment peak;
5. process/substance;
6. capability range;
7. enquiry/close.

### Ending

The persistent stitch trace stops behaving like decoration and becomes the contextual enquiry path. The selected program/garment label is retained beside the action.

### Explicit bans

- bento/card-grid storytelling;
- repeated sticky/pin sections with the same choreography;
- generic centred hero;
- full-page continuous generated video;
- decorative 3D with no information role;
- invented client/product evidence;
- price/stock/cart UI;
- more than two heavy scrub/video acts;
- project-specific colour leaking into global Fares chrome.

### Device palette

At least four families, never the same primary family twice in succession:
- parallax;
- kinetic;
- reveal;
- pin;
- pan;
- flow + in;
- project-specific pointer response where useful.

## Home feeling curve

1. quiet authority;
2. curiosity;
3. credibility;
4. anticipation;
5. **delight + comprehension — peak**;
6. assurance;
7. possibility;
8. confidence.

Scene 05 receives the visibly largest interaction/scroll span. Scene 04 is intentionally quieter immediately before it.

## Home scroll score

| Beat | Primary device | Supporting device | Initial span | Why |
|---|---|---|---:|---|
| Recognition | `parallax` | `kinetic` | 1.4vh | Depth is the first premium signal; no expensive pin before the visitor understands the proposition |
| Identity | `pin` | `reveal` | 1.7vh | Hold the relationship long enough for planes to reorganize into system logic |
| People | `pan` | `reveal` | 2.4vh | Lateral travel correctly reads as a set/range |
| Transition | `flow + in` | custom stitch trace | 0.8vh | A short quiet breath before the peak |
| **Seam Handoff** | **custom signature + pin** | parallax/scale | **3.2vh** | Largest span; the actual model-to-garment relationship is the memorable product idea |
| Substance | `reveal` | flow + in | 1.3vh | Calm reading interval after the peak |
| Range | `pan` | restrained pointer response | 1.6vh | Options/capabilities read laterally |
| Commitment | `kinetic` | custom stitch trace | 1.0vh | The trace resolves into the action; no dead footer tail |

Primary family order avoids repeating the same family twice in a row and uses more than four distinct families.

No scrubbed generated video is required for this first real-asset build. If a later real video asset earns a scrub act, keep the Scrollcraft maximum of two and re-score the page.

## Route grammars

### Work — Gallery / catalog
Objects/projects behave like a walkable collection with factual museum-style labels. One real project is better than a grid padded with fictional ones.

### KGC project — Chaptered editorial with Seam Handoff peak
The project is a readable case study, not another homepage. Chapters establish organization, stages, program logic and garment detail. The custom handoff is reused because it is the project's product continuity, not a generic transition.

### Garments — Gallery / catalog
Every real garment uses one consistent label schema. No price/cart/stock language.

### Garment detail — Technical/editorial inspection
Large truthful photography, front/back state, direct callouts over visible evidence, and contextual enquiry. No invented exploded layers.

### Enquiry — Quiet live surface
The motion stops. Context and action are clear, keyboard/touch behavior is conventional, and the page does not make a form theatrical.

## Mobile refinement

After desktop is composed:
- keep persistent compact navigation;
- design a portrait composition rather than cropping desktop blindly;
- focus one subject/garment at a time;
- compress non-informational holds;
- give the Seam Handoff a vertical/portrait choreography;
- maintain >=44px touch targets;
- keep a skip path past long kinetic sequences;
- validate multiple phone heights and Arabic RTL;
- re-check desktop after mobile changes.

## Reduced motion

The stitch trace becomes a static connective diagram.
All object relationships and labels remain present.
Pinned spans collapse to ordinary readable sections.
No understanding depends on animation.
