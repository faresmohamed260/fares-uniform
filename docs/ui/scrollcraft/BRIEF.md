## 1. Vibe and references

Client-confirmed direction:
- bright simple luxury;
- editorial fashion;
- tactile manufacturing;
- dimensional and kinetic;
- calm at rest, memorable in motion;
- premium enough to sit conceptually beside Dior / Chanel / Saint Laurent / Louis Vuitton-level restraint without cloning any brand.

Web references are implementation/composition research, not visual assets to copy. See `REFERENCE_BOARD.md`.

## 2. Scroll journey

The complete public experience should establish:

1. **Recognition:** Fares designs uniform programs, not isolated commodity garments.
2. **Identity:** an organization has a visual/operational identity before it has individual clothing items.
3. **People:** a program must work across real people, roles/stages and daily use.
4. **Continuity:** the worn look and the individual garment are one story.
5. **Peak / inspection:** the garment seen on the person becomes the exact real garment the visitor can inspect.
6. **Substance:** design, sampling, manufacturing and handover explain why the system can be delivered.
7. **Range:** the model can flex across education, hospitality, restaurants/cafés, healthcare and corporate teams without pretending those sectors are the same brand.
8. **Commitment:** enquiry begins with retained project/garment context.

Supporting routes:
- Work = real project archive / stories;
- Project = organization-specific program narrative;
- Garments = museum-like collection, not ecommerce;
- Garment detail = truthful inspection;
- Enquiry = calm context-aware conversion.

## 3. Energy curve

- Opening: quiet authority.
- First movement: curiosity.
- Project reveal: credibility.
- Program progression: growing engagement.
- Model-to-garment handoff: highest intensity and delight.
- Manufacturing proof: deliberate calm.
- Sector breadth: possibility.
- Enquiry: confidence and control.

The page must not be loud throughout. The peak needs contrast.

### Peak sentence

Assistant-authored from Fares's repeated requirements:

**“It’s the site where the uniform you see on the person becomes the real garment you inspect, without the story cutting away.”**

This is the moment a visitor should be able to describe later.

## 5. Signature move

### Seam Handoff

A thin pattern/seam line is the site-specific continuity device.

- In the neutral Fares shell it behaves like a restrained patternmaking/stitch trace.
- Inside a project it may inherit a real project garment geometry only when that geometry exists in the supplied media.
- In KGC, the actual diagonal panel language may influence the project-scoped trace.
- The line persists through the model → garment transition.
- At the peak, the line aligns the worn High look with the real polo packshot and becomes the inspection guide.
- It later carries the selected program/garment context into enquiry.
- Reduced-motion renders the same relationship statically.

This is custom page behavior, not a Scrollcraft parameter change.

## 6. Aesthetic range

Target: **premium-minimal + editorial + kinetic**.

Reject:
- generic SaaS;
- bento grids;
- glassmorphism as a system;
- ecommerce marketplace cards;
- permanent floating pills everywhere;
- gratuitous WebGL;
- “AI demo” effects;
- clay/diorama default art;
- an entire page made of identical sticky sections.

## 7. World structure

**Distinct scenes connected by one persistent design language**, not a single continuous 3D world.

Reason:
- Fares needs both emotional storytelling and useful project/catalog navigation;
- real current assets come from several photographic contexts;
- forcing them into one continuous generated world would violate the real-asset/no-fake boundary;
- Scrollcraft explicitly treats continuous worldflight as expensive and appropriate only when geography itself is the story.

## Pain / Person / Promise

### Pain
Uniform buying is usually presented as disconnected products. That makes it difficult for an organization to judge whether identity, roles, comfort/use, garments and manufacturing will still feel coherent as one program.

### Person
Primary: a decision maker responsible for a school, restaurant group, hospitality property, healthcare organization or corporate team.

Secondary: an individual/customer browsing actual garment options after the organizational program has been established.

### Promise
**Fares translates an organization’s identity and operational needs into a coordinated uniform program that still reads as one team when real people are wearing individual pieces.**

## Primary action

**Discuss a uniform program.**

The same action language should be preserved throughout the public story; contextual routes may add human-readable program/garment context without changing the core action.
