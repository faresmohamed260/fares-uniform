## Why this candidate is different

The rejected D-060 candidate `9ca2215bdbdd4455cd00ca94769119605af97952` made the global site feel like a KGC/school experience. D-061 resets the homepage to Fares as a multi-sector master brand.

The new homepage therefore:

- uses an organization-neutral graphic hero with no KGC/client imagery;
- establishes six business environments before any client story;
- explains the global Fares system as identity -> roles -> function -> garments -> manufacturing;
- introduces KGC only in a later **Selected Work** chapter;
- keeps a real garment example inside a broader garment-universe chapter rather than turning the homepage into ecommerce;
- uses a quieter manufacturing/craft sequence after the high-expression brand/sector chapters;
- ends with the global **Discuss a uniform program** action.
